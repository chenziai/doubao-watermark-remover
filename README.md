# 🎬 豆包水印移除工具

一个强大的浏览器插件，专门为处理用豆包生成的图片和视频而设计。快速去除水印，支持批量处理和自定义参数。

## ✨ 功能特性

### 📷 图片处理
- ✅ 支持多种格式（JPG, PNG, WebP 等）
- ✅ 可调节水印移除强度（0-100%）
- ✅ 实时预览效果
- ✅ 一键下载处理后的图片
- ✅ 支持拖拽上传

### 🎥 视频处理
- ✅ 支持多种视频格式（MP4, WebM, MOV 等）
- ✅ 自定义视频时长（5-60秒）
- ✅ **15秒视频优化** ⭐
- ✅ 可调节水印移除强度
- ✅ 多档次质量选择（480p/720p/1080p）
- ✅ 实时处理进度显示
- ✅ 支持拖拽上传

### 使用指南

#### 处理图片
1. 点击插件图标打开面板
2. 切换到"📷 图片处理"标签页
3. 点击上传区域或拖拽上传图片
4. 调节"水印移除强度"滑块（建议 40-60%）
5. 点击"🧹 移除水印"按钮
6. 预览效果，满意后点击"⬇️ 下载图片"

#### 处理视频
1. 切换到"🎥 视频处理"标签页
2. 点击上传区域或拖拽上传视频
3. 配置参数：
   - 视频时长限制：设置为 15 秒（或您需要的长度）
   - 水印移除强度：调节为 30-50%
   - 输出质量：选择合适的分辨率
4. 点击"⚙️ 处理视频"
5. 等待处理完成，进度条会实时显示
6. 点击"⬇️ 下载视频"保存结果

## 🔧 技术栈

- **视频处理**：FFmpeg.js（在浏览器中运行 FFmpeg）
- **样式**：现代化 CSS Grid 和 Flexbox

## 🎯 工作原理

### 图片水印移除算法
1. **加载图片**：使用 Canvas API 加载用户上传的图片
2. **像素分析**：检测半透明或高亮度像素（水印特征）
3. **智能移除**：
   - 降低水印像素的不透明度
   - 应用色彩混合以融合水印区域
   - 使用高斯模糊平滑边界
4. **输出处理**：转换为 PNG 格式保证质量

### 视频水印移除算法
1. **视频解析**：提取视频帧序列
2. **帧处理**：对每一帧应用图片水印移除算法
3. **时长控制**：剪辑至指定长度（如 15 秒）
4. **重新编码**：使用指定的质量参数重新编码视频
5. **输出生成**：生成可下载的视频文件

## ⚙️ 配置选项说明

|------|------|------|--------|

## 🐛 常见问题

### Q: 为什么处理后的图片/视频质量下降？
A: 这是正常的。为了有效移除水印，需要进行像素级处理，这可能会对原始质量有轻微影响。建议使用较低的强度值（40-50%）以平衡效果和质量。

### Q: 支持哪些文件格式？
A: 
- 图片：JPG, PNG, WebP, GIF, BMP
- 视频：MP4, WebM, MOV, AVI, MKV

### Q: 处理大文件会不会卡？
A: 对于超大文件（>100MB），处理可能会比较慢。建议先压缩文件后再处理。

### Q: 能批量处理吗？
A: 目前支持单个文件处理。后续版本会考虑添加批量处理功能。
